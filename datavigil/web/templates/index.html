Schema gate — break the batch on schema drift

Pin the selected dataset's schema as a baseline version, then Run gate after each new extract — a removed column or type change (e.g. customer_id string → int) fails the gate. The same check runs from the CLI (datavigil gate FILE) for batch jobs.

Batch — run a manifest

Run several checks at once from a manifest — the same job list the CLI (datavigil batch manifest.yml) and ECS runs execute. Paste a JSON manifest below (YAML also works from the CLI); source_file / target_file auto-register file sources.

Audit & Report

Audit this table profiles the selected dataset, runs the quality checks, finds anomalies and explains the failures — then export the result as a DOCX or PDF report. Audit whole schema does this for every table in the selected source (no dataset needed) and produces one consolidated report.
